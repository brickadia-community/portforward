Port Forwarding

Get players connecting to your Brickadia server.

Brickadia uses UDP 7777

Before you read

  • Ignore the Network Utilities thing on portforward.com.
  • Dedicated servers perform much better than servers hosted from the in-game menu.

Port forwarding instructions

  1. Visit this guide website.
  2. Find your router by model.
  3. Follow the instructions. When you get to the point where it becomes relevant, the port you want is UDP 7777.

Connection troubleshooting

  1. Check that port 7777 is forwarded for UDP.
  2. Check that the computer the port is forwarded to has the same IP as the IPv4 Address shown when you run ipconfig in cmd.
  3. Check that there is only one active adapter when you run ipconfig in cmd. Inactive ones may say "Media Disconnected".
  4. Check that FirewallAdvanced SettingsInbound Rulesbrickadia-win64-shipping is checked for public or private networks.
  5. Check that Ethernet (or Wireless) SettingsClick the connected networkNetwork profile is the same as the one from the firewall settings.
  6. Check that under Ethernet (or Wireless) SettingsChange Adapter Options only one network connection is Enabled and Connected.

Other things to note

If you have multiple networks at the same time

  • Make sure you forward for the address of whatever adapter Brickadia is using.
  • If you are running Hamachi, this is likely a problem. Try killing the task and disabling the adapter.

If your router asks for a Local IP and an External IP

  • Leave the section that does not have Start/End Port or Protocol alone.
  • Set Local IP Address to the IPv4 Address from ipconfig.
  • Set External IP Address to 0.0.0.0.

If your router asks for a Source IP and a Destination IP

  • Set Source IP Address to 0.0.0.0.
  • Set Destination IP Address to the IPv4 Address from ipconfig.
